# 未实现顶栏模块（占位页）

> **视图：** `topNav` ∈ { viewConfig, basicConfig, system, org, download }  
> **模块：** 占位  
> **生成：** 2026-05-25

## Overview

顶栏除「首页」「报表查询」「报表配置」外，其余模块点击后主区域显示统一占位文案 **「功能演示占位」**，无侧栏、无业务逻辑。

## 占位模块清单

| topNav ID | 顶栏标签 | 特性 |
|-----------|----------|------|
| viewConfig | 视图配置 | 无下拉 |
| basicConfig | 基础配置 | 有下拉箭头（未实现菜单） |
| system | 系统管理 | 有下拉箭头 |
| org | 组织管理 | 无 |
| download | 下载管理 | badge=3 |

## Interactions

- **触发：** 点击顶栏对应项
- **行为：** `setTopNav(id)`，渲染居中灰色提示文字
- **侧栏：** 不显示（sidebar=null）

## API Dependencies

无。

## Page Relationships

- **From：** 顶栏任意时刻可切换进入
- **To：** 切换至已实现模块即离开占位

## Business Rules

- 产品规划时需补充各模块 PRD；当前原型 intentionally 留空
- download 的 badge 仅为视觉演示，点击后仍进入占位页
