# 平台首页

> **视图：** `IntegratedReportPlatform.topNav = "home"`  
> **模块：** 首页  
> **生成：** 2026-05-25

## Overview

综合报表平台的默认落地页。展示 Hero 横幅与 **5 套业务模板**卡片网格，用户点击任意模板即进入**仪表板编辑器**，并在返回时可回到本页。

```
┌─────────────────────────────────────────────────────┐
│ 顶栏：综合报表平台 | 首页(激活) | 报表查询 | ...      │
├─────────────────────────────────────────────────────┤
│ Hero 横幅（PlatformHeroBanner）                      │
├─────────────────────────────────────────────────────┤
```

## Fields

### Hero 区域

| 元素 | 类型 | 说明 |
|------|------|------|
| 标题 | 静态文案 | 平台品牌与价值主张（PlatformHeroBanner） |
| 背景 | 装饰图 | 来自 platformHomeAssets |

### 业务模板区

| 元素 | 类型 | 说明 |
|------|------|------|
| 区块标题 | 文本 | 「业务模板」 |
| 副标题 | 文本 | 「选择模板进入编辑器，或在侧栏查看已发布报表」 |
| 模板数量 | 文本 | 「共 5 套」 |
| 模板卡片 ×5 | 可点击卡片 | 考核分析 / 产品分析 / 客群分析 / 效益分析 / 营销后评价 |

### 模板卡片（TemplateMarketCard）

| 字段 | 说明 |
|------|------|
| 封面图 | 各模板独立封面（PLATFORM_TEMPLATE_COVER_IMAGES） |
| 模板名称 | 来自 TEMPLATES.name |
| 点击行为 | 打开仪表板编辑器，传入对应 templateIndex |

## Interactions

### 页面加载

- 默认进入综合报表平台时 `topNav = "home"`，渲染本页
- 5 张模板卡片等宽网格排列（max-width 1600px）

### 选择模板

- **触发：** 用户点击某模板卡片
- **行为：** 调用 `onSelectTemplate(templateIndex, "home")` → App 切换至 `view = "editor"`
- **返回：** 编辑器顶栏「← 返回首页」回到本页

### 顶栏切换

- 用户可切换至「报表查询」「报表配置」等模块，本页隐藏

## API Dependencies

| API | 状态 | 说明 |
|-----|------|------|
| 模板列表 | Mock | 硬编码于 `dashboardModel.TEMPLATES` / `MARKET_TEMPLATES` |
| 封面图 | 静态资源 | `public/templates/*.png` |

## Page Relationships

- **From：** 应用启动默认页；编辑器返回首页；顶栏「返回首页」
- **To：** 仪表板编辑器（选模板）
- **Data coupling：** 无

## Business Rules

- 首页仅展示 `MARKET_TEMPLATE_IDS` 中的 5 套模板，不含空白模板
- 卡片为 `compact` + `coverOnly` 模式，侧重封面展示
