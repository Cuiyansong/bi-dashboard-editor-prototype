# 报表查询 — 营销后评价

> **视图：** `topNav=reportQuery` + `report-post-evaluation-main`  
> **模块：** 报表查询  
> **生成：** 2026-05-25

## Overview

营销后评价模板的专用**明细报表查询页**。以「客户号 × 支付渠道 SUM 指标」表格展示营销达标后评价数据，支持日期筛选与分页（Mock）。

## Layout

```
┌──────────┬──────────────────────────────────────────┐
│ 左侧树   │ 面包屑（可选）                            │
│          ├──────────────────────────────────────────┤
│          │ Tab 标签：{报表标题}                      │
│          ├──────────────────────────────────────────┤
│          │ 筛选：日期起止 + [查询]                   │
│          ├──────────────────────────────────────────┤
│          │ 数据表格（客户号 + 多指标列）              │
│          ├──────────────────────────────────────────┤
│          │ 分页：总计 N 条 | ‹ 1 2 3 … ›            │
└──────────┴──────────────────────────────────────────┘
```

## Fields

### 筛选区

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| 日期（起） | date | 否 | 2026-04-28 | 日期输入 |
| 日期（止） | date | 否 | 2026-04-28 | 日期输入 |

### 表格列

| 列 | 格式 | 说明 |
|----|------|------|
| 客户号 | 文本/数字 | 主键列 |
| 指标列 ×N | 数字 | 来自 POST_EVAL_INDICATOR_FIELDS，空值显示「-」 |

### 分页

| 字段 | 说明 |
|------|------|
| 每页条数 | POST_EVAL_PAGE_SIZE |
| 总条数 | POST_EVAL_TOTAL_ROWS（Mock 常量） |
| 页码按钮 | 最多展示 5 个页码 + 末页 |

## Interactions

### 页面加载

- 默认选中 `report-post-evaluation-main`
- 加载第一页 Mock 行数据

### 查询

- **触发：** 点击「查询」
- **行为：** 原型中**不刷新数据**（按钮无绑定逻辑）

### 分页

- **触发：** 点击页码或 ‹ ›
- **行为：** 切换 `page` 状态，切片 `POST_EVAL_REPORT_ROWS`

### 日期修改

- **触发：** 修改日期输入
- **行为：** 仅更新本地 state，不触发查询
